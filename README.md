# LAPELC²

Site público do Laboratório de Pesquisa da Linguagem, do Cérebro e do Comportamento Humano (FALE/UFAL).

Endereço: https://fonufal.github.io/lapelc/

O site foi implementado a partir dos modelos visuais aprovados. O pacote `site-bundle.zip` contém as páginas HTML, CSS, JS, logotipo oficial e imagens; o workflow `.github/workflows/pages.yml` extrai as páginas no repositório e publica no GitHub Pages.

Páginas: Início, Laboratório, Pesquisa, Infraestrutura, Rastreamento ocular, Eletroencefalografia, Pessoas, Produção e Contato.

Equipe: a página Pessoas usa nomes e fotografias do cadastro público do fonUFAL; a lista de vínculos específicos ao Lapelc² será revista na etapa editorial. As ilustrações e imagens experimentais são demonstrações visuais, não dados científicos.

Antes de publicar conteúdos definitivos, conferir dados biográficos e publicações.

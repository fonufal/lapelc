01 / COMO FUNCIONA

Como
funciona?

Registro do olhar

Utilizamos um eye tracker de alta precisão para registrar as posições do olhar enquanto os participantes realizam tarefas.

Processamento dos dados

Os dados são processados para identificar fixações, sacadas e padrões de exploração visual, em sincronia com os estímulos apresentados.

Análise e interpretação

Analisamos os padrões de olhar para inferir processos cognitivos como atenção, processamento linguístico, tomada de decisão e compreensão.
